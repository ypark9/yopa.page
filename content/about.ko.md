# 이 사이트를 운영하는 이유

저는 만들고 운영하면서 배우고, 실제 시스템을 통과한 내용을 기록하는 소프트웨어 엔지니어 박윤수입니다.

이 사이트는 제가 계속 성장하고 있다는 공개된 증거입니다. 실험, production 운영에서 배운 점, 잘못 알았던 내용의 수정, architecture 결정을 다른 개발자가 업무에서 다시 사용할 수 있는 자료로 만듭니다. 오래된 접근이 더는 안전하지 않다면 발행 이력을 숨기지 않고 현재 유지되는 글로 연결합니다.

## 여기서 찾을 수 있는 것

- security, cost, 운영 경계를 분명히 한 AWS와 Agent 시스템
- tradeoff를 생략하지 않는 software architecture와 platform 결정
- Salesforce, Python, TypeScript, DevOps와 self-hosting field note
- 여러 근거를 하나의 실무 판단으로 연결하는 Article Atlas Expedition
