상태: 편집 초안; 자동 발송 금지

## 이번 달에 배운 것

Agent prototype은 모델이 어떤 작업을 끝낼 수 있다는 사실을 보여줍니다.
하지만 권한 경계가 안전한지, 실패를 관측할 수 있는지, 복구 경로가 있는지는
증명하지 못합니다. 이제 이런 운영 경계를 출시 뒤의 인프라 작업이 아니라
Agent 설계의 일부로 다루고 있습니다.

## 새로 만들거나 검증한 것

첫 한영 Article Atlas Expedition을 만들었습니다. Agent 분류와 managed
service 경계에서 출발해 governed delivery, zero trust, 실제 migration 판단까지
이어지는 다섯 개의 stop입니다. 모든 결론을 같은 확신으로 말하지 않고 각
stop에 evidence 수준을 표시했습니다.

## 수정하거나 폐기한 판단

첫 브라우저 테스트에서 미묘한 구현 오류를 발견했습니다. 링크와 stop 카드가
같은 식별자를 사용해 다섯 개가 아니라 열 개로 계산됐고, 진행 상태 갱신이
중단됐습니다. 정적 빌드와 unit test는 통과한 상태였습니다. 선택자를 고친
뒤 실제 방문자 흐름을 보호하는 regression test도 추가했습니다.
