## What I learned

An agent prototype proves that a model can complete a task. It does not prove
that the surrounding system has safe authority boundaries, observable failure
modes, or a recovery path. I have started treating those operating boundaries
as part of the agent design rather than post-launch infrastructure work.

## What I built or verified

I built the first bilingual Article Atlas Expedition: a five-stop route from
agent taxonomy and managed-service boundaries through governed delivery, zero
trust, and a real migration decision. Each stop identifies its evidence level
instead of presenting every conclusion as equally proven.

## What I corrected

The first browser test exposed a subtle implementation bug: links and stop
cards shared an identifier, so the journey counted ten objects instead of five
and stopped updating. Static builds and unit tests had passed. The fix was not
just a selector change; the regression test now protects the visitor loop.
